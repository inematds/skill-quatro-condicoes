How it works

A fair test, without jargon

It works like a blind taste test: the same dish made four ways, with an outside taster who doesn’t know which is which.

🍽️ 1. Four identical dishes, four recipes

The same task runs four times, each in a separate kitchen: with nothing, only the general rules, only the skill, and both together. No run sees what another one did.

🙈 2. The taster doesn’t know which is which

The answers are shuffled and labeled A, B, C, and D for an AI from another company (Codex). It scores them from 0 to 10 and gives a one-sentence reason. Only afterward does the test reveal which was which.

🔁 3. More than once

AI doesn’t give the same answer every time. That’s why the test runs each condition three times and shows the average and variation. If the score varies a lot, it warns you before you decide.

📋 4. The verdict

At the end, you get direct answers: the skill helps, makes no difference, or gets in the way; the general rules help or get in the way; and if the two together make things worse, they conflict.

⚠️ What the test doesn’t promise

It measures one task at a time: a skill might help with one request and not another. The taster is also an AI and can be wrong, so an average across several runs is more useful than a single score. And the test doesn’t fix anything on its own: it shows the problem, and you decide what to do.

When AI refuses

Often, the restriction isn’t your fault

The companies behind the most advanced AI systems sell around the world and protect themselves from the strictest laws, such as Europe’s AI law and the risk of lawsuits in the United States. To avoid taking chances, they train AI to refuse when in doubt, and that restriction applies even in countries where those laws don’t apply.

🔎 1. Find out where the restriction comes from

If AI refuses even without any of your instructions, the restriction comes from the model. If it refuses only with your rules, one of them is confusing AI: find it and rewrite it.

⚙️ 2. Move repeated steps into a program

A task that’s always the same doesn’t need AI every time. Ask AI to write a small program once to handle that step. The program has no opinions, doesn’t refuse, and costs nothing each time you use it.

🔓 3. Use an open model

Some AI models run on your own computer and can be adjusted to refuse less often. The Make It Your Own Model kit shows you how and how to measure before and after.

Removing the model’s restriction doesn’t change the rules where you publish: you’re still responsible for what it produces.

Common questions

Before you start

Do I need to know how to code?

No. You paste the request, AI sets up the test, you say yes, and read the verdict.

Does it cost anything?

The kit is free. The test uses the Claude Code and Codex subscriptions you already have, with no API key. It runs 12 short tests and one evaluation.

Why is the judge from another company?

So AI isn’t scoring itself. If you don’t have Codex, you can use Claude as the judge.

Does it change my skills?

No. Each run uses a separate copy. The test only reads and shows the results.

Should I delete my skills from time to time?

Testing is better than deleting. Whenever a new model comes out, run the test: keep skills that still help and revise ones that get in the way.

Does it work with Codex?

The runs use Claude Code. Codex acts as the judge and can also read the kit and set up the test for you.
